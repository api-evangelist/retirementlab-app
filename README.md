Retirement Lab provides a free, no‑account retirement simulation tool that lets users explore multiple future scenarios, compare outcomes across 31 countries, and model taxes, spending, and savings. Built by Cedarwell Labs, it offers Monte Carlo forecasts, FIRE calculations, and detailed research blogs to help users make confident retirement decisions.

**Areas:** Retirement Planning · Simulation · Tax Modeling

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Retirement Lab: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
